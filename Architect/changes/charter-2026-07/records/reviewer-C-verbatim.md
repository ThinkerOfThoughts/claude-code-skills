## Coverage challenge (CH8) — required section

**CH8-1 (major — the same defect as FID-1's blast radius, from the harness side).** `1.5-criteria.md` Part B's own stated premise is: *"the charter's job is to make a cold reviewer behave a certain way. Text-presence cannot establish that, so the load-bearing criteria are behavioral."* Yet all four behavioral criteria (B-1 floor, B-2 completeness, B-3 severity, B-4 self-censorship) test only the **plan-red-team caller**. The **split-review caller inside `Divisible`** — half of "the two callers, both must be served" (`1-spec.md` §3) — gets zero behavioral verification; C-14 checks only that its aiming text is *present*. If the shipped charter's wording for the split-review caller is ambiguous or wrong in a way that causes a cold reviewer to approve an arbitrary cut, miss an orphaned remainder, or fail to flag a seam falling below the granularity floor, nothing in the harness would catch it — exactly the "unmeasured blast radius" this challenge exists to name. The same gap applies to four of the six lenses (factual, logical, missed-opportunity, fidelity) and to the **concurrency** conditional lens as a review technique (only the **position** lens gets any behavioral proxy, and even that is via B-1, which tests the *floor's* positioning, not a reviewer's actual application of the position-lens technique to a position-sensitive plan). Concrete scenario: a plan fixture with a genuinely position-sensitive prompt-assembly defect (the exact class C3/B16 exist to catch) is never run through a cold reviewer under the shipped charter to confirm the position-lens text actually produces the "test elements that didn't change" behavior the lens demands.

**CH8-2 (minor — noted, not gating).** No criterion behaviorally verifies the demotion rule (C-08/S14): that a reviewer contesting its own or a prior severity logs an entry, and that demoting a blocker/major without the human owner doesn't happen silently. Given this project's own documented "unearned clean verdict" failure mode (`ATTEMPT-2-STATE.md` §8 item 2), a fixture where a reviewer is tempted to quietly downgrade a finding would have been in scope for the same reasons B-3/B-4 exist.
