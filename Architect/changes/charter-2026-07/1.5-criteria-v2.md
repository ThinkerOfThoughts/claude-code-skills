## Part C — Oracle-can-fail self-test (gates every Part-A result)

| ID | Criterion | Label |
|---|---|---|
| **N-M1** | **Deletion mutants.** For each positive assertion, `oracles/mutation-test.sh` generates a mutant with that rule's stated text removed from its owning file. Every assertion **must be KILLED** by its mutant. | gating |
| **N-M2** | **Relocation mutants — the mutant class this re-scope makes necessary.** For a sample of assertions, generate a mutant that **moves the rule into the wrong file** (a common rule into a role file, a role rule into the common core). The per-file assertion **must still KILL it**. A probe that greps the whole set instead of the owning file would survive, and would be measuring presence rather than **placement** — which is the only thing this element changed. | gating |
| **N-M3** | **Insertion mutants for the absence sweeps.** N-18, N-15, N-17 and N-11's no-decision-log clause assert **absence**; the correct mutant is **insertion** of the forbidden text. Each must FAIL on its insertion mutant and PASS on the clean set. | gating |
| **N-M4** | **Negative control.** ≥1 mutant whose expected outcome is **SURVIVED**, so the harness is observed printing a non-kill. A harness that has only ever printed `KILLED` has not been shown able to report a failure. | gating |
| **N-M5** | **The self-test's own invocation is pasted verbatim** into `8-harness.md`, arguments included, with the exact output of the clean run and of every mutant run. | gating |

**`ruleplace.sh` hygiene.** It will refuse to run with no argument and return a **usage exit code distinct
from a clean pass**, so a no-argument invocation cannot be misread as a pass — this project once "verified"
a checker exactly that way.
