# Stage 1.5 — Criteria: the acceptance bar for hardening cycle 1

Seeded from the finding set in `/home/zero/architect-dogfood-2026-07-24/FINDINGS.md` (one criterion
family per finding) plus the **standing skill self-check** criteria and the **stage-0 regression**
criteria (this run is **not** greenfield — see `0-baseline.md` B0.5).

Every criterion is **checkable**, labeled **gating/advisory with a reason**, and states its **oracle**
plus an **oracle-can-fail self-test** (ST1.5f): the oracle must be shown to fire on a known-violating
input before a PASS from it counts; until then that criterion's result is `verified = no`.

**Two oracle classes, deliberately:**

- **`S-` structural / per-site assertion.** The artifact is a **prompt assembly**, so the primary
  question is *"is the rule stated, at every site that must state it, consistently?"* Per ST1.5f these
  are written as **positive per-site assertions** (the required claim is **present at each named site**),
  never as bare absence sweeps. Where an absence sweep is unavoidable (F5's removed pre-creation, F7's
  removed overclaim) it is **paired with the positive assertion** and the text is **normalized first**
  (strip `**`/`*`/backticks, flatten line-wraps) — because a fragile matcher makes "absent" silently,
  wrongly true.
  **Shared oracle-can-fail self-test for the whole `S-` family:** materialize the **baseline tree** at
  `3771038` (`git show 3771038:Architect/<f>`) into a scratch dir and run the *same* checker against it.
  Every new-rule assertion **must FAIL** on the baseline (the baseline is the known-violating input, by
  construction — that is what the findings say) and every preserved-rule assertion **must PASS** on it.
  A checker that passes the baseline is not a working oracle and its criterion is `verified = no`.
- **`X-` execution / behavioral.** For each fix whose value is *what a runner does*, a **cold agent is
  handed only the new skill text + a fixture** and must reach the correct verdict. Each `X-` criterion
  has a **holed arm** (the known-violating fixture) and an **intact twin** (the same shape, defect
  removed) run by **separately-spawned** cold agents that never see the other arm — so the oracle is
  shown able to fail *and* shown to discriminate. Inspection of the prose is **not** satisfaction of an
  `X-` criterion (H3/H5).
