# Stage 1.5 — Criteria (PASS 2)

Pass 1 is at `1.5-criteria.v1-superseded.md`. Its label audit was challenged on two grounds this pass
answers: (a) **11 gating criteria were grep-only on behavioural paths**, and (b) **its oracles' own
self-tests were miscalibrated** (R1 could not pass its baseline replay). One criterion family per finding,
plus the new `S-PRD`, the standing self-checks, and the stage-0 regressions.

**Three oracle classes, each with a stated reason it is not a proxy** — this is the CH9 challenge answered
per criterion rather than blanket:

- **`S-` per-site assertion — used where THE TEXT IS THE BEHAVIOUR.** These files are prompts; for a fix
  whose whole content is *"this rule is stated, identically, at every site a runner reads"* (a canonical
  heading string, a template slot a runner copies, a pinned path, a declared predicate), a per-site
  assertion is the **direct** check, not a proxy for one. Written as **positive per-site assertions**;
  any absence sweep is **paired** with its positive assertion and run on **normalized** text.
- **`X-` execution — used where A RUNNER MUST *DO* SOMETHING.** For a fix whose content is a duty
  performed (join, spot-verify, ingest, stop-on-missing-config, audit an approval), text presence *is* a
  proxy and is not accepted. A **cold agent gets only the fixture + the relevant new stage text** and must
  reach the correct verdict. **holed arm** + **intact twin**, separately spawned, neither seeing the other.
- **`ORACLE-` instrument checks** — the two measurement lessons pass 1 recorded as prose and then violated
  (`ruleid-sitemap`, `idcollide`), now instruments with their own can-fail tests (`0-baseline.md` B0.7).

**Shared oracle-can-fail self-test for the whole `S-` family:** materialize the baseline tree
(`git show 3771038:Architect/<f>`) and run the *same* checker. **Every new-rule assertion must FAIL there;
every preserved-rule assertion must PASS.** A checker that passes the baseline is not an oracle.

`~` = `<WT>/Architect/`. Fixtures: `fixtures/X<n>-<name>/{holed,intact}/`. Oracles: `oracles/`.

**ID set (post-collision-check, `oracles/idcollide.sh` clean):** `PRD`, `JOIN`, `SEAM`, `BIND`, `KLB`,
`PRV`, `DIV`, `IDN`, `RES`, `CNC`, `CTX`, `XPM`, `IGM`, `DEP` — **15 with `PRD`**. `KIL`→`KLB` and
`ING`→`IGM` because `KIL` ⊂ `SKILL` (21 hits/4 files) and `ING` ⊂ `PLANNING`/`RULING`.

## Part A — the new organizing rule

### S-PRD — Every fact a gate reads has a named producer, at the stage that writes it **[gating]**
1. `PRD` is stated at `METHODOLOGY.md`, `SKILL.md`, `stages/stage-6.5-join.md`, `stages/stage-8-restart-resume.md`.
2. `METHODOLOGY.md` carries the **canonical `_status.md` schema as a single fenced block** with the key
   list of `2-plan.md` §1a, and **each key's writing stage named in that block**.
3. **Per-key producer assertion:** for **every** key in that block, the **stage file that writes it** states
   the write. Checked mechanically: for each (key, stage) pair in the canonical block, the key appears in
   that stage's file. *(This is the assertion whose absence produced 4 of pass 1's 5 blockers.)*
4. `METHODOLOGY.md` states the consequence: a predicate whose operand has no assigned producer is an
   **un-runnable check**, treated as a missing rule.
- **Reason gating:** it is the property whose absence bounced pass 1 at gate 4; without it every other
  Tier-1 criterion can pass while the machinery deadlocks.
- **Oracle:** `check.sh S-PRD` (parses the fenced block; asserts each key→stage pair).
- **Self-test:** baseline replay — no `PRD`, no schema block, zero pairs.
