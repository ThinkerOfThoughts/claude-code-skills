# Architect

The fourth sibling in the gated-discipline family — owning the verb **plan**.

| Skill | Verb | "Prove, don't declare" oracle |
|---|---|---|
| dragonfly | *diagnoses* | reproduce-on-demand + causal toggle |
| guarded-change | *changes* | measurable criteria met at a harness |
| data-distiller | *distills* | blindness structural; agreement counted |
| **architect** | **plans** | **completeness proven (contract + cold critics), not asserted** |

Architect produces a **complete, hole-free, adversarially-tested plan** and **proves that completeness
before the plan is presentable**. It guards the founding failure: a plan that *looked complete* but
shipped with a whole load-bearing section silently missing, caught only by a human.

- **Start here:** `SKILL.md` (the router — the rules up front, then the stage table).
- **Orientation / reference:** `METHODOLOGY.md` (why it exists, the Layer-2 config contract, the
  completeness mechanic, the recursion + recursive-orchestration model, the 7-section spine, the on-disk
  run tree, the stage index, and the cross-file rule index).
- **Per-stage procedure:** `stages/` (one file per stage) + `stages/charter.md` (the forked cold-review
  charter + the sixth Completeness lens).
- **Templates:** `templates/seed/` (the seed skeletons + the skeletonize/match/back-propagate mechanism;
  syncs to the git-tracked user-space catalog `~/.claude/architect/templates/`).
- **Worked config:** `examples/authoring-a-skill/` (the dogfood plan-type).

The skill files are **prompts** (a position-sensitive assembly); non-trivial edits take the full
**guarded-change** loop. The initial authoring run's change-records are under
`changes/initial-authoring-2026-07/`.
